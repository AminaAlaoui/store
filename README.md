About the Project

*Slubuy* is a dynamic online marketplace where users can **buy and sell products** on the same platform.  

## About the Project

Slubuy is an online marketplace where users can buy and sell products on the same platform. Every sale generates a 10% commission for the platform.
## Features

- Buy products from other users
- Sell your own products
- 10% commission on every transaction
- Secure login and registration
- Multilingual support
- Mobile friendly (PWA)
- Email notifications
- Spam and security protection

## Built With

- WordPress + WooCommerce
- Dokan (Marketplace)
- Elementor (Page Builder)
- WooPayments + PayPal
- Polylang (Multilingual)
- GoDaddy (Hosting)

## Author

- 🛒 **Buy** — Browse and purchase products from other users
